# Photos Folder

Put photos Zoe took in this folder.

Good file types:

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`

Example file names:

- `photo-2.jpg`
- `flower-closeup.jpg`
- `favorite-view.webp`

After adding a photo, open `index.html` and update the matching card in the Photos I Took section:

```html
<img class="photo-image" src="assets/photos/photo-2.jpg" alt="Short description of the photo.">
```

Privacy check: avoid uploading photos that show full names, school names, addresses, badges, schedules, license plates, or location details.
