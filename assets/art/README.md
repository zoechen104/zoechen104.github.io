# Artwork Folder

Put Zoe's artwork images in this folder.

Good file types:

- `.png`
- `.jpg`
- `.jpeg`
- `.webp`

Example file names:

- `art-1.png`
- `rainbow-garden.jpg`
- `paper-flower-craft.png`

After adding an image, open `index.html` and update the matching gallery card:

```html
<img class="art-image" src="assets/art/art-1.png" alt="Short description of the artwork.">
```

Privacy check: avoid uploading images that show full names, school names, addresses, badges, schedules, or location details.
