# Site Images Folder

This folder is for decorative website images, not Zoe's artwork gallery.

Current image:

- `portfolio-hero.png` is the decorative hero image used near the top of the page.

To replace it:

1. Add a new image to this folder.
2. Open `index.html`.
3. Find this line:

```html
<img src="assets/images/portfolio-hero.png" alt="Watercolor art supplies, ribbons, paper flowers, and a sketchbook on a cheerful desk.">
```

4. Change the `src` to the new file name.

Use safe decorative images only. Do not use a real child photo by default.
