# Files Folder

Put family-approved downloadable or displayable files in this folder.

Good file types:

- `.pdf`
- `.png`
- `.jpg`
- `.docx`

Example file names:

- `sample-art-collection.pdf`
- `story-example.pdf`
- `project-photo.png`

After adding a file, open `index.html` and update a file card link:

```html
<a class="text-link" href="assets/files/story-example.pdf" target="_blank" rel="noopener">Open story-example.pdf</a>
```

Privacy check: review files before uploading. Do not include full names, school names, home addresses, email addresses, phone numbers, birthdays, schedules, or private event details.
