How to publish changes to website on Google:
Normally, when we change things, it only changes the files on our computer. We need to do some extra steps so that Google sees this change.

1. Go to the third section in the left sidebar of VS Code called "Source Control".
2. Stage the changes by pressing the "+" button on files under "Changes".
3. Write a short message describing the changes you have "staged".
4. Press "Commit" and then look below under "Outgoing Changes" to press the "Push" button (the one with arrow pointing upward).
